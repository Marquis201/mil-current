# Military Play

## 🎯 Что такое Military Play?

**Military Play** — это ролевой сервер в **Garry’s Mod (GMod)**, посвящённый жанру **Military RP**. 

> **Основной Сценарий:** Противостояние между силами **НАТО** и **Российской Федерации**.
